# DocsBuddy – Medical Appointment System

This is a college project that implements a medical appointment
management system with a focus on data confidentiality.

## Tech Stack
- Frontend: React + Tailwind CSS
- Backend: Node.js + Express
- Database: MySQL (phpMyAdmin)

## Roles
- Admin: Assigns doctors and manages appointments (no access to medical files)
- Doctor: Views assigned patients and uploads final reports
- Patient: Books appointments and receives reports via email

## Key Features
- Role-based access
- Secure handling of medical data
- Doctor assignment based on specialization
- Clean dashboards for Admin and Doctor

## Note
This project uses demo data and is intended for academic purposes only.
